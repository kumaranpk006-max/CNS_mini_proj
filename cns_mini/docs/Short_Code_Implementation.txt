1. Introduction
The AI-Based Phishing URL Detection System is a Java-based cybersecurity application developed to analyze website URLs and identify fraudulent phishing domains using Machine Learning. The application utilizes Weka's Random Forest ensemble algorithm trained on the benchmark UCI Phishing Websites dataset. It features an interactive Java Swing security dashboard providing instant URL verification, risk classification (LOW, MEDIUM, HIGH), probability scores, and a feature inspection breakdown.

2. Objectives
• To develop a Java-based cybersecurity desktop application for phishing URL detection.
• To extract lexical, structural, and security features from input URLs in real time.
• To train a Random Forest ensemble model (100 decision trees) using Weka 3.8.6.
• To achieve high classification accuracy (>95%) with low false negative rates.
• To provide an intuitive Java Swing security operations interface.
• To ensure safe defensive analysis without downloading untrusted remote web payloads.

3. Proposed System
The proposed system integrates four primary modules: a Java Swing user interface, an input URL normalization and validation module, a 30-attribute feature extractor, and a Weka Random Forest classification engine.

When the user enters a URL and selects "Analyze URL", the application extracts 30 discrete attributes matching the UCI dataset schema (e.g., IP address presence, URL length, subdomains, URL shorteners, hyphen tokens, and SSL state). The extracted vector is passed to the trained Random Forest classifier, which calculates class probabilities and assigns a risk tier. The Safe Simulation feature demonstrates detection against multiple predefined legitimate and phishing vectors.

6.1 Main Phishing URL Detection Program (PhishingURLDetectorMain.java)
The main program coordinates the execution flow: it accepts a target URL, invokes the feature extraction module, passes the extracted attributes to the trained Random Forest model, and displays the predicted class, confidence percentage, and assessed risk level.

--------------------------------------------------------------------------------
package com.phishingdetector;

public class PhishingURLDetectorMain {
    public static void main(String[] args) throws Exception {
        String testUrl = "https://www.google.com";
        System.out.println("Inspecting URL: " + testUrl);

        // 1. Extract 30 lexical and structural features from URL
        int[] featureVector = URLFeatureExtractor.extractFeatures(testUrl);

        // 2. Load trained Random Forest model and ARFF header schema
        ModelPredictor predictor = new ModelPredictor();

        // 3. Perform machine learning classification
        PredictionResult result = predictor.predict(featureVector, testUrl);

        // 4. Output security assessment
        System.out.println("Prediction : " + result.getPredictedClass());
        System.out.println("Risk Level : " + result.getRiskLevel() + " RISK");
        System.out.println("Confidence : " + result.getConfidencePercentage());
        System.out.printf("P(Legit)=%.2f%%, P(Phish)=%.2f%%\n",
                result.getLegitimateProbability() * 100.0, result.getPhishingProbability() * 100.0);
    }
}

6.2 URL Feature Extraction (URLFeatureExtractor.java)
This module extracts the discrete numerical attributes from the input URL matching the exact schema of the training ARFF dataset (1 = Legitimate, 0 = Suspicious, -1 = Phishing), including IP presence, URL length, shorteners, '@' symbols, domain hyphens, subdomains, and HTTPS tokens.

--------------------------------------------------------------------------------
package com.phishingdetector;

import java.net.URI;
import java.net.URL;

public class URLFeatureExtractor {
    public static int[] extractFeatures(String rawUrl) {
        int[] f = new int[30];
        try {
            URI uri = new URI(rawUrl.startsWith("http") ? rawUrl : "http://" + rawUrl);
            URL url = uri.toURL();
            String host = url.getHost() != null ? url.getHost().toLowerCase() : "";
            String proto = url.getProtocol() != null ? url.getProtocol().toLowerCase() : "http";

            // 1. having_IP_Address: -1 if IP used as host, else 1
            f[0] = host.matches("^(?:[0-9]{1,3}\\.){3}[0-9]{1,3}$") ? -1 : 1;

            // 2. URL_Length: <54 -> 1 (Safe), 54-75 -> 0, >75 -> -1 (Phishing)
            int len = rawUrl.length();
            f[1] = (len < 54) ? 1 : (len <= 75 ? 0 : -1);

            // 3. Shortining_Service: -1 if shortener domain, else 1
            f[2] = (host.contains("bit.ly") || host.contains("tinyurl.com") || host.contains("t.co")) ? -1 : 1;

            // 4. having_At_Symbol: -1 if contains '@', else 1
            f[3] = rawUrl.contains("@") ? -1 : 1;

            // 5. double_slash_redirecting: -1 if '//' appears after pos 7
            f[4] = rawUrl.lastIndexOf("//") > 7 ? -1 : 1;

            // 6. Prefix_Suffix: -1 if domain has '-', else 1
            f[5] = host.contains("-") ? -1 : 1;

            // 7. having_Sub_Domain: dots in host (excluding www)
            String clean = host.replace("www.", "");
            int dots = clean.length() - clean.replace(".", "").length();
            f[6] = (dots <= 1) ? 1 : (dots == 2 ? 0 : -1);

            // 8. SSLfinal_State: 1 if trusted HTTPS, 0 if suspicious, -1 if HTTP
            f[7] = "https".equalsIgnoreCase(proto) ? (f[5] == -1 ? 0 : 1) : -1;

            // 11. port: 1 if standard (80/443), -1 if non-standard
            int p = url.getPort();
            f[10] = (p == -1 || p == 80 || p == 443) ? 1 : -1;

            // 12. HTTPS_token: -1 if 'http(s)' embedded in domain name
            f[11] = (host.contains("https-") || host.contains("http-")) ? -1 : 1;

            // Defensive Baseline for remaining DOM/external attributes
            for (int i = 8; i < 30; i++) {
                if (i != 10 && i != 11) f[i] = (i == 13 || i == 14 || i == 25 || i == 28) ? 0 : (i == 26 ? -1 : 1);
            }
            f[18] = 0; // Redirect: { 0, 1 }
        } catch (Exception e) {
            f[0] = 1; f[1] = 1; f[7] = -1;
        }
        return f;
    }
}

6.3 Machine Learning Prediction (ModelPredictor.java)
This module loads the trained Weka Random Forest model, attaches input features to the dataset header template, executes classification, calculates class probability distributions, and derives the risk level.

--------------------------------------------------------------------------------
package com.phishingdetector;

import weka.classifiers.Classifier;
import weka.core.*;
import java.io.File;

public class ModelPredictor {
    private Classifier classifier;
    private Instances header;

    public ModelPredictor() throws Exception {
        // Load serialized Random Forest model and empty header template
        this.classifier = (Classifier) SerializationHelper.read("model/phishing_model.model");
        weka.core.converters.ArffLoader loader = new weka.core.converters.ArffLoader();
        loader.setFile(new File("model/model_header.arff"));
        this.header = loader.getStructure();
        this.header.setClassIndex(this.header.numAttributes() - 1);
    }

    public PredictionResult predict(int[] featureValues, String url) throws Exception {
        // Convert 30 integer values to a Weka DenseInstance
        Instance inst = new DenseInstance(header.numAttributes());
        inst.setDataset(header);
        for (int i = 0; i < 30; i++) {
            inst.setValue(header.attribute(i), String.valueOf(featureValues[i]));
        }
        inst.setClassMissing();

        // Get class probabilities: index of '-1' (Phishing), index of '1' (Legitimate)
        double[] probs = classifier.distributionForInstance(inst);
        double phishProb = probs[header.classAttribute().indexOfValue("-1")];
        double legitProb = probs[header.classAttribute().indexOfValue("1")];

        String predClass = (legitProb >= phishProb) ? "LEGITIMATE" : "PHISHING";
        double confidence = Math.max(legitProb, phishProb);
        String risk = (confidence >= 0.75) ? (predClass.equals("LEGITIMATE") ? "LOW" : "HIGH") : "MEDIUM";

        return new PredictionResult(url, predClass, confidence, risk, legitProb, phishProb);
    }
}

6.4 Java Swing Dashboard GUI (PhishingDetectorGUI.java)
This module provides the desktop graphical user interface. It contains a URL input field, action buttons for URL analysis and clearing output, and a scrollable monospaced terminal area for displaying real-time security assessment results.

--------------------------------------------------------------------------------
package com.phishingdetector;

import javax.swing.*;
import java.awt.*;

public class PhishingDetectorGUI extends JFrame {
    private JTextField urlInput = new JTextField("https://www.google.com", 32);
    private JTextArea outputConsole = new JTextArea(16, 55);
    private JButton analyzeBtn = new JButton("▶ Analyze URL");
    private JButton clearBtn = new JButton("Clear Output");

    public PhishingDetectorGUI() {
        setTitle("AI-Based Phishing URL Detection System");
        setLayout(new BorderLayout(8, 8));

        // Control Panel
        JPanel topPanel = new JPanel(new FlowLayout(FlowLayout.LEFT));
        topPanel.add(new JLabel("Target Website URL:"));
        topPanel.add(urlInput);
        topPanel.add(analyzeBtn);
        topPanel.add(clearBtn);
        add(topPanel, BorderLayout.NORTH);

        // Terminal Output Console
        outputConsole.setFont(new Font("Consolas", Font.PLAIN, 12));
        outputConsole.setEditable(false);
        add(new JScrollPane(outputConsole), BorderLayout.CENTER);

        // Action Listeners
        analyzeBtn.addActionListener(e -> checkURL());
        clearBtn.addActionListener(e -> outputConsole.setText(""));

        pack();
        setLocationRelativeTo(null);
        setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
    }

    private void checkURL() {
        try {
            String url = urlInput.getText().trim();
            PredictionResult res = URLPredictionService.analyzeURL(url);
            outputConsole.append("======================================================\n");
            outputConsole.append(res.isPhishing() ? "SECURITY ALERT: Phishing Detected!\n" : "SECURITY ASSESSMENT: Legitimate\n");
            outputConsole.append(String.format("URL        : %s\nPrediction : %s\nRisk Level : %s\nConfidence : %s\n",
                    url, res.getPredictedClass(), res.getRiskLevel() + " RISK", res.getConfidencePercentage()));
            outputConsole.append("======================================================\n\n");
        } catch (Exception ex) {
            outputConsole.append("[ERROR] " + ex.getMessage() + "\n");
        }
    }

    public static void main(String[] args) {
        SwingUtilities.invokeLater(() -> new PhishingDetectorGUI().setVisible(true));
    }
}
